User Group Field makes Craft’s user groups available as content. Let authors select one or several groups, then use those choices in templates, notifications, access rules, or project-specific workflows.

Add the field to an entry, user, global set, or another supported layout and choose whether it accepts one group or several. Authors select from the user groups already configured for the Craft project.

## Features

- **Craft user groups:** Choose from the groups already managed by the project.
- **Single selection:** Model a content decision that has one responsible group.
- **Multiple selection:** Associate content with several groups when the workflow requires it.
- **Field layouts:** Place the choice on supported Craft element types.
- **Twig values:** Use selected group models and handles in project templates.
- **Element indexes:** Add the selected group values to supported Craft index columns.
- **UID queries:** Filter element queries by a selected user group's UID.
- **Field-level rules:** Configure selection mode and available options for each field.
- **Structured group data:** Templates receive group models rather than a copied label, keeping handles and project configuration available for conditional presentation or custom application logic.
